# Hero model references

32 hero class references for 3D reconstruction, generated 10 November 2026 with the built-in imagegen tool. Each PNG contains one full-body hero with empty hands; weapons are added in-game. Existing class portraits supplied identity references for 24 classes; eight new classes used their written briefs.

Open [index.html](index.html) for the full-size linked gallery. Contact sheets show the full set. [prompts.json](prompts.json) records prompts, references, dimensions and SHA-256 checksums; [PROMPTS.md](PROMPTS.md) preserves the supplied brief. Generation notes record the additional direction on class variety and open silhouettes.

These are reconstruction source images. Downstream 3D meshes and rigs still need validation.
