Crowns of Caern: Warbound
=========================

An original dark-fantasy real-time strategy game.
Source code: https://github.com/CrownsofCaern/Crowns_of_Caern_rts

Starting the game
-----------------

Windows: run CrownsOfCaernWarbound.exe. The game is not code-signed, so
  Windows SmartScreen may warn you. Choose "More info", then "Run anyway".

macOS: move "Crowns of Caern- Warbound.app" to Applications and open it. The
  app is not notarized by Apple, so the first time macOS refuses to open it.
  Open System Settings > Privacy & Security and choose "Open Anyway", or run
  xattr -dr com.apple.quarantine "/Applications/Crowns of Caern- Warbound.app"
  in Terminal.

Linux: run ./CrownsOfCaernWarbound.x86_64.
