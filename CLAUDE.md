# Crowns of Caern: Warbound: notes for contributors and coding agents

Dark-fantasy real-time strategy with RPG heroes, set in the world of the turn-based Crowns of Caern
(github.com/CrownsofCaern/Crowns_of_Caern_4X). Godot 4.5.1, GDScript, GL Compatibility renderer.
README.md documents every system in detail; read it first.

## Hard rules
- Original content only: no names, art, lore, factions, creatures or UI taken from other games
  (genre mechanics are fine).
- `src/sim/` is headless and deterministic: no Nodes, all randomness through `GameRng`, units processed
  in id order. Views (`src/ui/`, `src/menu/`) read state and change it only through `Skirmish.act()`
  (`WorldCommands`, also what travels online in lockstep).
- Data-driven: content in `data/*.json`, validated (`HeroCatalog`, `ItemCatalog`, `CampaignCatalog`).
  Never hand-edit `data/units.json`: it is generated by `tools/sync_from_main.py` (tune the tables there;
  needs `CAERN_MAIN` pointing at a main-game checkout).
- `src/world3d/`, `assets/nature`, `assets/terrain3d`, `data/biomes.json` are owned here; the main game
  keeps a copy for its 3D battles. Keep that layer free of Warbound-only types.
- Tests with every feature (`tests/unit/test_*.gd`). Run only the tests related to a change
  (`./run_tests.sh <filter>`); run the full suite on batches of merged work.
- GDScript: static typing, tabs, snake_case. After adding a `class_name`, run
  `godot --headless --path . --import` and commit the `.gd.uid` files.
- Cloud containers render on software GL (about 1 FPS): use the `tools/*_shots.gd` stills, check speed on
  real hardware.

## Direction
Dark fantasy, not cute: dark gothic light, blood-red skies, matte (not glossy) materials. Sound: subtle and
harmonic. Art and visual upgrades are done by the project owner; do not start art work unless asked.
Campaigns follow the main game's campaigns chapter by chapter (odd = hero/RPG chapter, even = war chapter).

## Commands
    ./run_tests.sh [filter]
    godot --path .
    godot --headless --path . --script res://tools/balance.gd -- 12 20 out.md concord,hollow
    godot --headless --path . --script res://tools/campaign_probe.gd -- <chapter> join <level>
    xvfb-run -a godot --path . --rendering-driver opengl3 --script res://tools/look_shots.gd -- /tmp/shots
